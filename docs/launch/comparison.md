# Comparison vs. alternatives

(Published at `/compare`: `content/pages/compare.md`.)

| | ClientWrap | Spreadsheet + email | Reporting tools (AgencyAnalytics, DashThis) | Invoicing tools (FreshBooks, Bonsai) | Client portals (SuiteDash, Copilot) |
|---|---|---|---|---|---|
| Any metric in client's own units | ✓ | manual | mostly marketing channels | ✗ | ✗ |
| Monthly written summary + next step | ✓ | manual | partial | ✗ | ✗ |
| Invoices with pay button | ✓ (your Stripe) | ✗ | ✗ | ✓ | ✓ |
| Friendly reminders, quiet hours, tone guardrails | ✓ | ✗ | ✗ | basic | basic |
| Renewal, case study (client-approved), referral from results | ✓ | ✗ | ✗ | ✗ | ✗ |
| One no-login client link | ✓ | ✗ | ✓ | invoices only | login |
| Signed webhook + Zapier/Make/n8n | ✓ | ✗ | limited | limited | limited |
| White-label + custom domain | Tier 3 | — | higher tiers | higher tiers | ✓ |
| Price | from $29/mo, or lifetime | free | $50–300+/mo | $15–50+/mo | $20–100+/mo |

**Positioning line:** Reporting tools stop at charts, invoicing tools stop at the invoice, and portals need a login. ClientWrap connects results → payment → renewal in the one link your client actually opens.

**Honest "not for you if":** you need native ad-platform connectors, a CRM or project management.
